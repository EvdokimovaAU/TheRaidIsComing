
# The Raid is Coming

**The Raid is Coming** - 3D Tower Defense в сеттинге фэнтезийного средневековья, разрабатываемая на Unreal Engine 5.8.

Игроку предстоит защитить Капитолий от волн противников, самостоятельно выстраивая оборону и распоряжаясь ограниченным количеством золота.

## Особенности игры

- **Свободное строительство.** Башни можно размещать в любой подходящей точке выделенных зон, а не только в заранее определённых слотах.
- **Преграды.** Игрок может перекрывать проходы, изменяя маршруты противников. Разные типы врагов по-разному реагируют на препятствия: обходят их или разрушают.
- **Разные типы башен.** Башни лучников обеспечивают быструю атаку, а магические башни способны поражать несколько целей одновременно.
- **Поведение противников.** Вражеские юниты отличаются характеристиками и логикой перемещения. Маги также могут создавать защитные барьеры для союзников.
- **Ночные волны.** Ближе к концу уровня постепенно темнеет. Ночью игроку необходимо управлять прожектором, подсвечивая врагов, чтобы башни могли по ним стрелять.
- **Строительство во время боя.** Оборону можно перестраивать непосредственно во время наступления, но возведение сооружений занимает время.

## Основная информация

- **Жанр:** Tower Defense
- **Движок:** Unreal Engine 5.8
- **Язык программирования:** C++
- **Платформа:** PC
- **Возрастное ограничение:** 12+
- **Количество уровней:** 3
